Cómo usar este checklist
Un documento de descubrimiento y aceptación de alcance para la nueva instancia.

1. Recorra los roles en orden

Los roles están ordenados de menor a mayor alcance funcional. El Analista Financiero cierra la lista porque es un rol endosable: hereda automáticamente todos los permisos del sistema.

2. Marque las funciones deseadas

Cada fila tiene una casilla. Marque solo las funcionalidades que desea para esa instancia. Si no marca ninguna, se entiende que no se incluye el rol o que se revisará en una segunda sesión.

3. Complete la decisión por rol

Al final de cada rol encontrará un cuadro para indicar si incluye todo, solo lo marcado o si no incluye el rol. Agregue observaciones y firme.

4. Firme el acta de alcance

La última página resume la selección por rol. Con la firma del cliente y del proveedor, el alcance queda listo para convertirse en el backlog de implementación.

Definición de terminado (DoD): una funcionalidad seleccionada se considera terminada cuando está configurada, probada con un usuario del rol correspondiente y aceptada por el cliente en la demostración.

Glosario mínimo

  • RBAC: control de acceso basado en roles; cada rol agrupa permisos.
  • Rol: conjunto de responsabilidades asignadas a un usuario.
  • Permiso: autorización concreta para ejecutar una acción.
  • Endosable: rol que hereda todos los permisos del sistema.
  • Instancia: copia configurada del sistema para una institución.

Cómo se convierte en backlog

Cada función marcada se transforma en una historia de usuario con criterios de aceptación. Las funciones no marcadas quedan fuera del alcance de la primera entrega y pueden incorporarse en una fase posterior.

Épicas sugeridas: seguridad y roles, socios, operación de sesión y cobros, créditos e inversiones, reportes y auditoría.

Nota de alcance: la matriz de permisos puede ajustarse por institución. El checklist permite seleccionar funciones específicas, incluso dentro de un mismo rol; las funciones no seleccionadas quedan fuera de la primera entrega.
